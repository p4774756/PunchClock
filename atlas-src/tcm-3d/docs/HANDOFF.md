# 3D 穴位人体项目 Handoff

更新：2026-09-18（America/Toronto）

## 项目目标

在 `https://tcm.jic.io/3d/` 提供一个用于中医授课与演示的 3D 人体：显示穴位与经络，可选择针、灸、砭石、指压、刮痧、火罐等工具，在皮肤表面移动并演示效果；疼痛关联属于教学可视化，不作为诊断或疗效承诺。

旧版铜人页面 `https://tcm.jic.io/bronzeman` 保持不动。

## 已完成内容

- 以 BodyParts3D 4.0 的成人男性外部模型为基础，保留 Human Atlas 的 MIT 来源历史；来源与限制写入 attribution。
- 已收录 362 个有名称的穴位、14 条经络显示路径和 670 个贴附皮肤的穴位实例。经络线是可视化路径，不代表人体内部精确走行。
- 默认工具为针；六类工具都可在皮肤上定位、拖动和播放教学演示。
- 工具接近穴位时会吸附到最近的可选穴位，并保留穴位编码与侧别，因此针移动到穴位后可选中穴位并更新详情。
- 实现疼痛部位与相关穴位的教学关联示例；效果为演示反馈，未宣称治疗效果。
- 人体表层使用真实皮肤感的着色表现；男性会阴前侧做成连续平滑皮肤，无生殖器展示；移除了“结构拆解”控制。
- 修复足底涌泉附近的黑色圆形遮挡：基座在低角度隐藏，足底补光改善。
- 头顶区域隐藏遮挡穴位的头发 shell（`FJ2813`），百会等头顶部穴位从俯视可见。
- 完成手机全屏适配：竖屏、横屏、安全区与工具栏折叠均已处理。
- 英文介绍已压缩至约 502 词：`docs/INTRODUCTION.en.md`。
