# 贡献指南

感谢关注本项目。欢迎通过 Issue 与 Pull Request 参与改进。

## 开发流程

1. Fork 本仓库并创建功能分支
2. 本地安装依赖：`npm install`
3. 开发并自测：`npm run dev`
4. 提交前确认：`npm run build` 通过
5. 发起 Pull Request，说明动机与验证方式

## 提交建议

- 使用清晰的提交说明（例如：`fix: 修正督脉穴位吸附偏移`）
- 一次 PR 尽量只做一类改动
- 不要提交密钥、Token、`.env`、个人数据
- 大体积资源请优先压缩；新增模型需补充 `ATTRIBUTION.md`

## 行为准则

请保持友善、建设性的讨论；勿提交与项目无关的内容或恶意代码。
