下載小寶貝

在此下載小寶貝桌面端 jar。請先安裝 Java，再以 jar 啟動。

下載 SKLbaby.jar約 {{HOME_CLIENT_SIZE}}

伺服器尚未附帶可下載的 jar，請向管理員索取。

目前版本：v{{HOME_CLIENT_VERSION}}

如何執行

需要已安裝 Java {{HOME_JAVA_VERSION}} 或以上。

  1. 下載完成後在 Finder 或檔案總管找到 jar 檔。
  2. 第一次執行請在 jar 上右鍵 → 打開，通過安全性提示。
  3. 之後可在終端機執行：java -Xdock:name=小寶貝 -jar SKLbaby.jar
