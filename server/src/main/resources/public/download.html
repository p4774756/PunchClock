在此下載小寶貝桌面端。可下載安裝檔（內建 Java，雙擊即可），或下載 jar 自行用 Java 執行。

Mac（Apple 晶片 M1 以後） Mac（Intel） 下載 Windows 安裝檔（.exe）

不確定晶片類型？請點蘋果選單 > 關於這台 Mac，在「晶片」或「處理器」欄位查看。

安裝檔尚未提供，請稍後再試或向管理員索取。 下載 XiaoBaobei.jar（v{{CLIENT_VERSION}}）

伺服器尚未附帶可下載的 jar，請向管理員索取。

安裝檔（macOS／Windows）

下載後雙擊安裝或執行即可，不必先安裝 Java。安裝檔尚未數位簽章，首次開啟請依下列方式通過系統提示。

  • macOS：在 App 或安裝程式上右鍵 → 打開，通過 Gatekeeper 提示後即可使用。
  • Windows：若 SmartScreen 顯示「Windows 已保護你的電腦」，請按更多資訊，再選仍要執行。

jar 檔（進階）

需要已安裝 Java {{JAVA_VERSION}} 或以上。

  1. 下載完成後在 Finder 或檔案總管找到 jar 檔。
  2. 第一次執行請在 jar 上右鍵 → 打開，通過安全性提示。
  3. 之後可在終端機執行：java -Xdock:name=小寶貝 -jar XiaoBaobei.jar
