回辦公室

把上班、下班等打卡交給小幫手自動處理。電腦需已安裝 Java {{JAVA_VERSION}} 或以上。

下載 jar（v{{CLIENT_VERSION}}）

伺服器尚未附帶可下載的桌面端，請向管理員索取。

macOS 首次開啟

  1. 下載完成後在 Finder 找到 jar 檔。
  2. 第一次執行請在 jar 上右鍵 → 打開，通過安全性提示。
  3. 之後可在終端機執行：java -jar punchclock-client-standalone.jar

使用方式

安裝後在程式裡填入公司打卡頁面與按鈕，設定好時間就會在背景自動幫你打卡。今天打得怎樣，可到辦公室裡的打卡鐘查看。
