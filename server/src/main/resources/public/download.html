回辦公室

打卡與排程在桌面端完成。需要已安裝 Java {{JAVA_VERSION}} 或以上。

下載 SKLbaby.jar（v{{CLIENT_VERSION}}）

伺服器尚未附帶可下載的桌面端，請向管理員索取。

macOS 首次開啟

  1. 下載完成後在 Finder 找到 jar 檔。
  2. 第一次執行請在 jar 上右鍵 → 打開，通過安全性提示。
  3. 之後可在終端機執行：java -Xdock:name=新光小寶貝 -jar SKLbaby.jar

門口打卡機對應此桌面端：設定公司打卡網址與按鈕後，由程式在背景排程自動點擊。
