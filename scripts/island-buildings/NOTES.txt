PunchClock 島嶼四棟建築 GLB 產生器
================================

重建（需 Blender 4.2+，本機路徑可自行調整）：

  blender -b --factory-startup --python scripts/island-buildings/build_all.py -- \
    server/src/main/resources/public/models

也可單棟：

  blender -b --factory-startup --python scripts/island-buildings/build_tcm.py -- out.glb
  （另有 build_shop.py、build_casino.py、build_lab.py）

座標與慣例
----------
- 匯出後 glTF / Three.js：原點 = 佔地中心，y=0 為地面。遊戲端把模型放在 y = G（草地厚度 0.2）。
- Blender 內 Z 朝上；本地 +Z（正面）在 Blender 是 -Y，glTF 匯出時會轉成 +Z。
- 佔地數字對齊 island-layout.js 的 BUILDINGS（main 20d0a53）：
    shop           w=4.75  d=3.2
    casino         w=2.4   d=1.9
    tcm-site       w=2.3   d=1.8
    computer-site  w=2.3   d=1.8
- 檔名與建築 id 相同：public/models/<id>.glb
- 具名節點；招牌平面叫 sign_face，帶 0..1 UV，給既有 canvas 招牌貼圖用。
  （sign_face 的 V 已對 glTF／Three.js 對調，文字才是正的。）
- 發光材質名稱必須是 windows_glow、lantern_glow、neon_glow，code 端依名稱換成遊戲的 mat()，才會跟著日夜與 emissive 走。
- 根節點 extras：footprint_w、footprint_d、ground_y、door_local、building_id；另有空物件 label_anchor。
- 門口：賭場、推拿館、研發樓在本地 +Z。莫卡手搖的進門在西牆（本地 -X，door_local ≈ [-2.375, 0, -0.85]），對齊既有 entry.at = { x: -3.09, z: -0.85 }，不要改到 +Z。

壓縮選擇
--------
四棟未壓縮合計約 555 KB。用 gzip -9 可壓到約 91 KB；meshopt 反而比較大（約 226 KB）還要多載 MeshoptDecoder。
因此進 repo 的是未壓縮 GLB，不依賴解碼器。Javalin 6 預設會開 gzip，但 .glb 若被當成 application/octet-stream，有可能不會被壓。建議在 ServerApp 的 /models 靜態目錄加上 mimeTypes.add("model/gltf-binary", "glb")，讓瀏覽器協商 gzip。即使沒壓到，555 KB 也比現有 bgm-main.ogg（約 1.1 MB）小，可以接受。

授權
----
模型與腳本是為 PunchClock 島嶼新做的 low-poly 資產，沒有第三方網格或貼圖。招牌文字貼圖由遊戲執行時畫在 sign_face 上，不包含在 GLB 裡。
